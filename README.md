# Business Analytics Dashboard — React

A simple analytics dashboard with summary metric cards, a revenue chart, and a searchable/sortable/paginated data table.

## Tech stack

- React
- Recharts (chart)
- react-icons (sidebar icons)
- Plain CSS (no UI framework)
- Data source: [JSONPlaceholder](https://jsonplaceholder.typicode.com/users) `/users` API

## Setup

Requires Node.js 18+.

```bash
npm install
```

## Run locally

```bash
npm start
```

Runs at `http://localhost:3000`.

To build a production version:

```bash
npm run build
```

Output is written to the `build/` folder.
